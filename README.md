ASHGATE is a 5v5 tactical round-based FPS in the browser: two bot squads, a bomb site with a fuse, a buy phase, 10 rounds, hand-rolled movement and ballistics, and procedural audio — vanilla three.js with no runtime dependencies.

## Run it

```sh
node serve.ts
```

Then open <http://localhost:8080>. `node main.ts` writes the submission output (game, screenshots and dossier) to `_out/`.
